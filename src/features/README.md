# 기능 폴더 작업 안내

각 폴더는 한 기능 담당자가 화면과 기능을 함께 소유하도록 분리되어 있습니다.

```text
기능 폴더/
├─ pages/       라우트에서 직접 여는 페이지
├─ components/  기능 내부에서만 재사용하는 컴포넌트
├─ api/         추후 Spring Boot API 요청 모듈
├─ types/       기능 전용 응답·요청 타입
├─ styles/      기능 전용 CSS
├─ mocks.ts     UI 개발용 임시 데이터
└─ index.ts     외부에 공개할 진입점
```

현재는 UI 단계이므로 필요한 폴더만 생성되어 있습니다. API 작업을 시작할 때도 다른 기능 폴더를 참조하지 말고 자신의 기능 폴더 안에 모듈을 추가해 주세요.
